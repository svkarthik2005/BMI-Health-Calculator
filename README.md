# 🩺 BMI Health Calculator

A simple and responsive BMI Health Calculator built using React, Node.js, and Express.

## 🚀 Features

- Calculate BMI using height and weight
- Input validation
- Health status display
- BMI history using browser localStorage
- Clear BMI history
- Dark/Light mode
- Loading message
- Error handling
- REST API using Node.js and Express
- Responsive design
- Postman API testing

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- CORS
- REST API

### Testing
- Postman
